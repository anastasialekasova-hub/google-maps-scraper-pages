# Google Maps Scraper — pages

Welcome, uninstall and feedback pages for the Google Maps Scraper Chrome extension, served via GitHub Pages.

- `/welcome/` — opens once after installation
- `/uninstall/` — feedback form, opens when the extension is removed
- `/feedback/` — "What should be better?" form, opened by a 1–3 star rating in the extension
- privacy policy: https://pinwisp.com/google-maps-scraper/privacy/
